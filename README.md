# Quick Response (QR) code generator

qr - (c) fenna

Usage: qr [OPTIONS]

Options:
  -z, --zoom <ZOOM>
          how much to zoom in on each pixel [default: 100]

  -c, --content <CONTENT>
          contents of the QR code [default: ""]

  -o, --output <OUTPUT>
          output file path [default: qr.png]

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
